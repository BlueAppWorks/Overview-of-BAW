# Blue App Works

## 設立趣旨
AIによって非エンジニア人材であっても、自身が欲しいアプリケーションをその場で生成して、身近な業務のために使えるようになっています。
Blue App Works では、Snoeflake のようなクラウドデータベースプロダクトを中核とするインフラレイヤーの抽象化技術を活用し、このようなアイデアから生み出されたアプリケーションの業務適用を支援します。
ボタンひとつで容易にデプロイし、隣の人と〜チーム内〜部門内〜全社で、規模を問わず必要な人たちのところに業務アプリケーションが届いて安全に使えるような仕組み化を支援します。

## 中核となる技術

### Snowflake Postgres
クラウドデータベースベンダーが提供する PostgreSQL サービスをバックエンドとするアプリケーション開発を支援します。
米 Snowflake 社が提供する「Snowflake Postgres」は、同社が従来より強みとする分析用データベース「Snowflake」とシームレスなデータ連携ができ、同プラットフォーム上で動作するマネージドコンテナ実行サービス「Snowpark Container Service」と接続することで社内業務アプリケーションを簡単にセキュアにデプロイして利用することができます。
アプリケーションの規模を問わず個人〜全社利用するためのインフラ環境はもはやクラウド側で抽象化され、個人の業務改善アイデアから生まれたアプリケーションを実行する環境で悩む必要はなくなります。

### Blue App Modules
このように生成されるアプリケーションは、自社 Snowflake 内の '権限さえあれば' 容易にデプロイして即本番利用できる環境が整っています。しかし、インフラ側の権限を適切に付与して行使させることや、各種コンピュートを起動・停止するといった「アプリケーションを使う以外の操作」を業務側の責務で実施させることは本質的ではありません。
Blue App Modules は Blue App Works が提唱する3つのモジュール化された仕組みによって
 * アプリケーションのデプロイ
 * 日々の利用
 * 統制の取れたIT環境で適切に利用

をサポートすることができます。

# Repositories
現在はいずれも Private Repository です。プロトタイプは動作しているため各種デモの紹介や実装技術の説明は可能です。

### BlueAppOperator
Snowflake上で稼働するアプリケーションを Blue App Operator 仕様に準拠するようにデプロイして「管理対象に登録」することで、アプリの起動停止をOperator経由で管理できるようにします。

### BlueAppBuilder
Dockerコンテナ等で実装されたアプリケーションを Operator に準拠する形で Snowflake Native App としてデプロイするデスクトップアプリケーションです。

### BlueAppGallery
Operator で管理対象に登録したアプリを一覧表示・検索するギャラリー機能と、ギャラリーから今使いたいアプリを起動して「使う」だけを実現するビジネスユーザー向けUXレイヤーです。SaaSとして提供を予定中。
